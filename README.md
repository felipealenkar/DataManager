# DataManager 1.2
Sistema de gerenciamento de Databases em PostgreSql

# Tecnologias Utilizadas
Linguagem: Delphi Athens 12.1

Arquitetura: Legacy POO.

Banco de Dados: PostgreSQL 18.

# Funcionalidades Principais

Criar, Renomear, Excluir, Fazer backup e restore de bancos de dados Postgres

# Como rodar o projeto
Instalar o PostgreSQL 18

Rodar o arquivo exe contido na pasta \DataManager\Win64\Release
